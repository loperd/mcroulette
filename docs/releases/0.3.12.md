# 0.3.12

Delivers 0.3.11, whose deployment stopped at the Identity and Security migrations: the migration job did not complete within its deadline and left no logs, so the API and frontend stayed on the previous release.

The migration step now checks that `voxel-vault-secrets` holds `IDENTITY_MIGRATION_DATABASE_URL` and `SECURITY_MIGRATION_DATABASE_URL` before it starts a job, and names any missing key. A job that does not complete is reported with its pods, logs and events. A failed job left by an earlier attempt is reported and replaced; each migration version runs in its own transaction and is recorded, so the new job continues where the failed one stopped. A job that is still running is left alone.

The 0.3.10 tag is removed: it was not on master's history. Its changes ship with 0.3.11.
