# 0.4.0

Prepares the 0.4.0 release from the published 0.3.13 source. This release changes version metadata and release tooling; it adds no new gameplay features. The existing gateway integration, owned backend contexts, chest and world content, and mobile rendering work remain part of the inherited product, rather than new features introduced in 0.4.0.

Preserves the migration and deployment fixes from 0.3.12 and 0.3.13: migration secret-key preflight, failure diagnostics, replacement of failed jobs while leaving active jobs alone, and explicit non-root UID/GID 65532 for both migration containers. The deployment workflow retains its migration-job regression check, Helm 3 pin, and API-before-frontend ordering. This release does not change authentication settings or database migrations and does not reset player data.

Release commits now take their description from the matching version's release notes instead of a hard-coded feature summary. The production command runner pipes the message into Git's stdin; a real-commit regression test protects this path. Release preparation requires explicitly staged changes, rejects unstaged or untracked work outside ignored paths, and checks that HEAD and the staged source tree remain unchanged during validation. The local release gates also include the migration-job regression test. The GLB decoder check creates its report directory so it can run in a fresh checkout. Unrelated knight assets and meshoptimizer development are outside this release.

Release preparation is not evidence of publication or successful deployment. Full release gates, API/frontend deployment and production smoke checks remain required before accepting 0.4.0; mobile browser emulation does not establish physical-device or Safari performance.
