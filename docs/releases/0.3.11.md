# 0.3.11

The 0.3.10 tag is not on master's history, so this release carries its changes as well (see [0.3.10](0.3.10.md)): the Quantum Relic chest, portable world packs and the mobile rendering work.

Moves the End and Dragon Reach worlds to 3D blockworld scenes: a floating chest island over the void, an obsidian tower ring with End crystals and healing beams, and a dragon that circles and sweeps low over the chest (tremor, gust and violet light). Removes the 2D pixel-world renderer and its scenes; every world now renders through blockworld.


Replaces product-owned authentication with the project instance of Overseer Gateway. Identity owns accounts, provider links and sessions; Security owns role bindings and versioned policies. Forward-only Goose migrations preserve account IDs, linked Telegram accounts and stored credentials before removing obsolete public authentication tables. Existing browser sessions require signing in again.

The API is private to the cluster and checks gateway provenance, current session validity, current roles and token grant limits. Provider linking rejects revoked sessions and mismatched account ownership. Inventory and Wallet have independent context implementations; the production economy cutover remains an explicit operator step.

Improves error recovery controls and fixes world initialization without a status listener. Opening animations advance by elapsed visible time under slow rendering. Mobile checks use Chromium viewport and CPU emulation; they do not establish physical-device or Safari performance.
