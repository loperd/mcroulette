# 0.3.10

Adds the Quantum Relic chest with PBR materials, an opening animation, a dedicated environment and a server-defined item catalog.

Introduces portable world packs with file, geometry, texture and resource-lifecycle validation. Updates scene preparation/review tools and removes obsolete mine scene experiments.

Improves mobile rendering: roulette draws a card-height strip instead of a full-screen transparent canvas, measures layout only when needed and pauses the obscured world. Physics loads separately, reducing the initial JavaScript module by roughly 79% in the optimization build. Preview cancellation works without `AbortSignal.any()`.

Adds a mobile regression probe with Chromium CPU throttling and frame statistics. Fixes lost transition time under slow mine frames and batches static ore crystals. Chromium emulation does not establish physical iPhone/Android or Safari performance.
