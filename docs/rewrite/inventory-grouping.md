# Группы инвентаря и показатели

Карточка — группа экземпляров, а не замена их данных. Ключ: caseId, status, четыре зоны palette (shell/panel/metal/accent), отдельные уровни повреждений корпуса и крышки, id награды для открытых. ID экземпляра, seed, техническая revision в ключ не входят: они сохраняются индивидуально. Разные узоры трещин одного уровня объединяются, превью показывает первый экземпляр; переход ведёт именно к нему, с его реальными метаданными.

Игроку показывается сохранность: 100% у целого сундука, шкала убывает при повреждении. Уровни каждой части: 100%; 75–99%; 50–74%; 25–49%; 0–24%. Общий индикатор использует худшее состояние двух частей. В группе показываются диапазоны сохранности; в выбранном экземпляре — точные проценты с округлением вверх. Показатель повреждения не равен вероятности выпадения награды.

Показатели по экранам:
- Инвентарь: количество в группе, состояние, уровни обеих частей, уровень износа и состояние. Палитра влияет на ключ группы и превью, но её внутренние зоны не показываются игроку. Фильтры/поиск применяются до группировки; количество отражает найденные экземпляры.
- Каталог типов: количество готовых к открытию экземпляров этого типа. У типа без выбранного экземпляра нет единого значения повреждений.
- Экран сундука: доступный запас типа, точный износ корпуса/крышки выбранного экземпляра, его палитра и статус.
- Награда: редкость, название и источник предмета, оставшийся доступный запас сундуков. Возврат — в инвентарь.

Проверены ключи группировки и границы уровней, 100 экземпляров в одном стеке, уменьшение стека при открытии, переход к реальному instanceId, показатели в каталоге, осмотре и награде. Сборка и UI-тесты проходят. При добавлении новых значимых визуальных/игровых свойств расширять ключ группировки и показатели совместно.
