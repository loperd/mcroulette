# Итерация 01: независимое ядро

Реализовано в ветке `rewrite-react-rapier`. Production UI и физика не входят в эту итерацию.

## Правила

`domain/item.ts`: валидирует данные и создаёт immutable snapshots. Пустой/дублированный каталог, нечисловой/отрицательный вес и неизвестная rarity отклоняются. Нулевые веса допустимы.

`domain/strip.ts`: shuffle → round → cap, уникальные slot ids, вставка отсутствующего приза в фактическую длину массива, корректный выбор среди совпадений. Каталог старого проекта даёт 39 карточек; King добавляет сороковую. Выбранный слот использует авторитетные title/image/rarity результата. Созданные массивы не меняют входные данные.

`domain/spin-plan.ts`: положение в единицах карточек, legacy-торможение и множитель времени, jitter внутри центральных 80% карточки. `positionAt` вычисляет положение по elapsed time, фиксирует точный конец после пропущенного кадра. Работает независимо от viewport и FPS.

RandomSource находится в domain как минимальный численный контракт; реализации случайности будут в адаптерах. Домен не импортирует application или browser API.

## Сценарий

`application/roulette-controller.ts` реализует входной порт RouletteSession. Инициализация ждёт каталог и assets, затем запускает падение. Open синхронно блокирует повторную команду и параллельно запускает выбор результата/открытие. Вращение ждёт обе операции. Затем контроллер последовательно проходит spinning → settling → revealing → prize-visible.

Close сбрасывает presentation, сохраняет состав ленты и возвращает ready. Следующее открытие получает новый sessionId и новый запрос результата.

Ошибка даёт сериализуемый failed state с recovery action. Retry сохраняет sessionId; если приз уже получен, повторный запрос не выполняется. Reset после ошибки возвращает ready. Abort wrapper завершает ожидание даже для адаптера, игнорирующего signal; поздний callback не меняет новую сессию. Реальные адаптеры обязаны также прекращать собственные эффекты/ресурсы при отмене.

Снимок состояния стабилен до изменения и подходит для useSyncExternalStore. Dispose терминальный, очищает подписки и пытается освободить все presentation adapters даже при ошибке одного из них.

## Проверки

`npm test`: 35 тестов, все проходят. Проверены endpoints индексов, 100 seeded наборов выбора целей, landing/jitter/FPS, обе последовательности завершения prize/open, duplicate commands, retry без повторного selection, задержанные callbacks, отмена загрузки и 100 полных циклов с fake ports.

Проверка domain/application выполнена локальным TypeScript 6.0.3 из npm-кэша: `tsconfig.domain.json` исключает DOM, `tsconfig.core.json` проверяет ядро целиком. Установленная проектная версия TypeScript 7 ещё не проверена: npm registry недоступен. Для обычного окружения предусмотрена команда `npm run typecheck:core`.

Фактические WebGL/WASM-ресурсы и поведение браузера ещё не тестировались. Полный React/Vite production build остаётся непроверенным до установки зависимостей. 100 fake-циклов проверяют orchestration и сохранение ленты, а не отсутствие утечек будущего renderer.
