# Voxel Vault

Продукт для владельцев Minecraft-серверов. Voxel Vault — название продукта; сервер может использовать собственный бренд в интерфейсе игрока.

Ender — первый рабочий кейс, а не тема всего продукта. Сейчас доводим его полный сценарий. В будущем — каталог разных сундуков, организованный по модели CS:GO: выбор кейса → его содержимое → открытие → результат. Конкретные категории и правила доступности пока не определены; не придумывать платёжную механику и баланс.

При расширении использовать описание кейса: id, название/коллекция, модель, узлы и клипы, каталог наград, палитра и профиль эффектов. Общими остаются состояния экрана, переходы, рулетка, физика и lifecycle эффектов. Ender-эффекты не должны становиться обязательными для всех моделей. Серверная интеграция определяет результат и выдачу; красивый экран награды не подтверждает доставку в Minecraft.

Текущий эффект приземления вынесен в ChestImpactEffects; цвет — параметр, эффект запускается один раз при приближении физического корпуса к полу. Частицы и импульс живут в общей Three.js-сцене и очищаются при reset/hide/dispose. Звук удара синтезируется; загружать чужие игровые звуки не требуется. Декоративные эффекты отключены при reduced motion. Полный реестр кейсов ещё не реализован.
