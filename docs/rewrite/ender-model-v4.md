# Ender v4 — простой силуэт, авторская поверхность

Обратная связь: исходный простой Ender был удачнее; v3 перегружен обвесом. Текущее направление — кубический сундук с крышкой и одним небольшим замком. Характер дают собственные пиксельные поверхности и палитра, а не дополнительные детали.

Текущий игровой файл public/models/ender-vault-v4.glb (~26 KiB, 216 треугольников). Blender: assets/chests/ender-v4/ender-vault.blend. Превью вариантов: mineral.png и obsidian.png; открытый вид — open.png. Оба варианта используют одну геометрию, это варианты оформления первой модели, не две дополнительные модели из плана.

Две оригинальные текстуры 32×32 созданы скриптом проекта с нуля. Исходные Minecraft/референсные изображения не использованы. Корпус полый, крышка имеет задний pivot и клип Vault.Open; замок целиком движется с ней. Узлы экспорта Body/LidAssembly нормализуются независимо от автоматических суффиксов Blender.

Минеральный вариант подключён в config/cases.ts. Палитра по умолчанию обновлена; геометрия совместима с контрактом метадаты, независимыми повреждениями корпуса/крышки и прежними эффектами открытия. Камера, макет и маршруты не изменены. Предыдущие более декоративные варианты сохранены отдельно.

Production build и test:all прошли, включая проверку реального экспортированного шарнира, материалов, текстур и отсутствия лишних сцен. Визуал остаётся кандидатом до отзыва пользователя.
