# Итерация 07: исходное кольцо и внутренний полукруг

Последующее уточнение пользователя: эта форма относится только к падению сундука. Она вынесена в статический ChestBackdrop позади сцены и видна в ready/resetting, скрыта начиная с opening. Из CanvasRoulette удалена целиком: в рулетке остаётся только полный круг линзы, без дополнительного внешнего кольца. Standalone canvas preview также показывает только линзу. Ниже сохранено описание геометрии формы падения; прежнее размещение позади ленты больше не актуально.

По уточнению пользователя и двум CS:GO-референсам восстановлена декоративная форма из `master:src/view/component/Circle.vue`. Это отдельный элемент от круглой маски увеличенной ленты: полое кольцо и меньший полукруг внутри него.

В исходнике форма рисовалась через Konva, не HTML: Circle с radius R и strokeWidth R, затем Arc с angle 180°, innerRadius 0 и outerRadius 0.45R. На Canvas 2D кольцо строится через evenodd fill с внешним радиусом 1.5R и внутренним 0.5R; нижний полукруг имеет радиус 0.45R и не касается кольца. Чёрный цвет и opacity 0.17 взяты из исходника. Responsive R также скопирован: max(width,height), делённый на 3/4/5/7/10 по границам 640/768/1024/1280.

Форма рисуется на том же canvas позади двух проходов ленты. Линза и логическая позиция рулетки сохранены. Высота preview/game viewport увеличена; на узких экранах используется квадрат, чтобы исходное кольцо не обрезалось прежней полосой 300/360 px. Полный визуальный паритет не подтверждён браузерной проверкой.

Два новых native Node-теста проверяют все responsive thresholds, пустой центр, геометрию нижнего полукруга, зазор, цвет и прозрачность. Весь базовый набор проверяется через npm test. Повторная типизация и UI tests в этом запуске недоступны: временные TypeScript/Happy DOM из /tmp удалены, зависимости проекта по-прежнему не установлены. Предыдущие успешные UI-проверки не объявляются проверкой новой формы.
