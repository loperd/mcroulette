# Спецификация переписывания MC Roulette

Дата: 2026-10-14. Цель — воспроизвести существующий продукт на современном стеке с hexagonal architecture, сохранив физическое падение сундука, его открытие, рулетку, звук и повторные циклы.

Это спецификация для реализации, а не утверждение, что приложение уже восстановлено и запущено. Поведение реконструировано по исходникам и GLB; сборка, worker и визуальные эталоны требуют отдельной проверки. Установка пакетов через shell сейчас ограничена отсутствием DNS-доступа к npm registry. Актуальные возможности библиотек проверены по официальным веб-источникам.

## Зафиксированные решения

React, строгий TypeScript, Vite, обычный Three.js и `@dimforge/rapier3d-compat`. Стек согласован пользователем. Версии указаны в package.json; успешная установка должна создать единственный npm lock-файл. Node 24 указан в .nvmrc. React отвечает за реактивный интерфейс, физика и покадровая анимация остаются в отдельных адаптерах. React Three Fiber, Redux и DI-framework в базовый стек не входят. [React](https://react.dev/reference/react/useSyncExternalStore), [Vite](https://vite.dev/guide/).

Исходный проект остаётся эталоном в ветке `master` (commit `b4496b37a73af10751796492fa83e2af757e061d`). По решению пользователя новая реализация создаётся с нуля в корне ветки `rewrite-react-rapier`; legacy-файлы удалены из рабочей версии. Отдельные каталоги `next/` и `legacy/` не нужны. Физика заменяется на Rapier. Декоративные круги и эффекты реализуются CSS/SVG; Konva, глобальный bus, классовые Vue-декораторы и DI-framework не переносятся. Ручная композиция зависимостей достаточна.

Статические JSON остаются работающим демо-источником. Выбор настоящего выигрыша не выдумывается: будущий API заменяет адаптер PrizeGateway. Цена открытия, баланс, аккаунты, выдача предметов, платежи и серверные вероятности отсутствуют в исходнике и не входят в эту спецификацию.

## Готовность результата

Новая версия считается готовой после выполнения критериев из behavior.md, production build и тестов, проверки отсутствия утечек на повторных циклах и визуального сравнения с эталоном. Документирование не заменяет эти проверки.
